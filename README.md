# NAMU 학원관리

학원 원장님이 수강생, 월 수강료 수납, 수입·지출, 상담 기록을 한곳에서 관리할 수 있는 브라우저 기반 MVP입니다.

## 실행

가장 간단하게 `index.html` 파일을 최신 브라우저에서 열면 됩니다. 별도의 설치나 서버가 필요하지 않습니다. 화면은 데스크톱과 모바일 크기에 맞춰 표시됩니다.

## 포함 기능

- 운영 대시보드: 재원생 수, 이번 달 수납과 미수금, 손익, 최근 기록
- 수강생 관리: 학교·학년·과목·연락처·수강료·메모 등록, 검색, 수정, 삭제 및 CSV 내보내기
- 수납 관리: 월별 청구, 수납 입력, 잔액 및 수납률 확인
- 학원 가계부: 수입·지출 추가 및 월별 합계, CSV 내보내기
- 상담 관리: 문의 등록, 검색, 상태 변경 및 기록 삭제
- 데이터 백업·복구: JSON 파일 다운로드 및 복구

## 데이터와 개인정보

초기 예시 정보는 모두 가상의 이름과 전화번호입니다. 입력한 데이터는 현재 브라우저의 `localStorage`에 저장되므로 같은 브라우저에서 이어서 사용할 수 있습니다. 서버 동기화, 사용자 로그인, 접근 권한, 자동 백업 기능은 구현되어 있지 않습니다. 실제 학생 정보를 입력하기 전에 학원 내부의 개인정보 보호 방식과 브라우저/기기 보안 설정을 확인하고, 정기적으로 백업 파일을 안전한 장소에 보관하세요.
