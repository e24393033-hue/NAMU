# NAMU 학원관리

원장과 직원이 개인 아이디로 로그인해 수강생, 수납, 학원 장부, 상담 내용을 관리하는 웹 앱입니다. 원장은 여러 지점을 만들고 지점 사이를 전환하며, 직원 계정은 원장이 지정한 지점 자료만 볼 수 있습니다.

## Windows에서 실행하기

1. Node.js 24 이상이 설치되어 있는지 확인합니다. 이 앱은 Node 내장 SQLite를 사용하며 별도 패키지 설치는 필요하지 않습니다.
2. `start-namu.bat`을 더블클릭합니다. 검은 창을 닫지 않은 상태로 둡니다.
3. 브라우저에서 `http://localhost:4173`을 엽니다.
4. 처음 한 번 원장 계정 이름, 아이디, 12자 이상의 비밀번호를 설정합니다. 화면을 살펴보려면 **가상 샘플 데이터로 시작**을 선택하세요.
5. 원장 계정으로 로그인한 뒤 **설정 및 데이터 → 직원 계정 관리**에서 직원별 계정을 추가합니다. 직원은 각자 받은 계정으로 로그인합니다.

서버를 중지하려면 `start-namu.bat` 창에서 `Ctrl+C`를 누릅니다. 데이터는 프로젝트 안의 `data/namu.sqlite`에 저장되어 서버를 껐다 켜도 남습니다. `data` 폴더는 Git에 포함되지 않도록 설정되어 있습니다.

## 입력자 확인

수강생·수납·가계부·상담 기록을 추가, 수정, 삭제할 때 로그인한 직원의 이름과 변경 시각, 변경 전·후 정보가 이력에 남습니다. 원장 계정은 **설정 및 데이터 → 최근 변경 이력**에서 확인할 수 있습니다. 직원 계정은 계정·백업 관리에 접근할 수 없고, 학원 업무 기록을 관리할 수 있습니다.

계정은 공유하지 마세요. 직원이 그만두면 원장 계정으로 해당 계정을 비활성화하세요. 직원은 각자 비밀번호를 바꿀 수 있습니다.

로그인 화면의 **아이디 찾기**는 직원의 확인 요청을 원장에게 전달하고, **비밀번호 찾기**는 직원 비밀번호 초기화 요청을 접수합니다. 기존 비밀번호는 확인할 수 없습니다. 가입 요청은 원장 승인 후 직원 계정이 됩니다. 이 기능은 이메일 인증을 하지 않으므로 원장이 별도 경로로 본인 확인 후 요청을 처리해야 합니다. 원장 계정의 아이디·비밀번호 분실은 이 시험판에서 자동 복구되지 않습니다.

## 암호화 백업과 복구

- 원장 계정으로 **설정 및 데이터 → 암호화 백업**을 선택하고 12자 이상의 백업 암호를 입력합니다.
- 내려받은 `.namu` 파일과 백업 암호를 서로 다른 안전한 곳에 보관합니다.
- 복구하려면 **백업 복구**에서 `.namu` 파일과 백업 암호를 선택합니다. 복구는 현재 학원 데이터와 변경 이력을 백업 시점 상태로 되돌립니다. 계정은 복구되지 않습니다.
- 백업 암호를 잊으면 복구할 수 없습니다. 정기적으로 백업하고, 복구 절차도 샘플 데이터로 먼저 확인하세요.

## 여러 지점 운영 배포

- [DEPLOYMENT.md](DEPLOYMENT.md)의 Docker 단일 서버 구성을 따라 HTTPS reverse proxy 뒤에서 실행할 수 있습니다. `.env.example`에 실제 도메인을 넣어 `.env`를 만들고, DNS와 TLS가 준비된 다음 배포하세요.
- 각 지점 데이터는 서버의 SQLite 저장소에서 분리됩니다. 원장은 모든 활성 지점을 볼 수 있고, 직원은 지정된 지점만 조회·수정할 수 있습니다. 직원 한 명은 한 지점에만 배정됩니다.
- 이 구성은 작은 학원의 단일 서버 운영을 위한 것입니다. 앱 인스턴스를 여러 대로 늘리면 안 됩니다. 고가용성, 다중 인증, 자동 외부 백업, 원장 계정 자동 복구는 제공하지 않습니다.
- 실제 학생 정보를 입력하기 전에는 HTTPS, 암호화된 서버 디스크, 별도 위치의 자동 백업 및 복구 훈련, 직원 권한, 개인정보 처리 절차를 점검하세요. 만 14세 미만 학생에 대한 법정대리인 동의 여부도 운영 절차에 반영해야 합니다.
- 첫 설치에는 가상 이름·연락처로 구성된 샘플 데이터가 표시됩니다. 샘플 데이터를 초기화하면 현재 데이터가 교체됩니다.

로컬 실행(`start-namu.bat`)은 계속 이 컴퓨터에서만 접속하는 체험 용도입니다. 여러 지점에서 함께 사용하려면 HTTPS 배포를 먼저 완료해야 합니다.

## 포함 기능

- 대시보드, 수강생·수납·가계부·상담 관리
- 개인 로그인, 원장 계정에서 직원 계정 추가·비활성화
- 다중 지점, 지점별 독립 자료, 직원별 지점 접근 배정
- 변경자·변경 시각·변경 전후 값을 기록하는 이력
- 백업 파일 암호화와 암호 입력을 통한 복구
- 수강생과 가계부 CSV 내보내기
